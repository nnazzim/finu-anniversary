❤️ FINU'S MEMORY GALLERY — HOW TO ADD YOUR REAL PHOTOS
========================================================================

Hi Nasim!
Here is how to add your own real photos of you and Finu:

1. Copy your photos into this folder:
   public/images/

2. Rename them to match the slots:
   - memory-01.jpg
   - memory-02.jpg
   - memory-03.jpg
   - memory-04.jpg
   - memory-05.jpg
   - memory-06.jpg
   - memory-07.jpg
   - memory-08.jpg
   - memory-09.jpg
   - memory-10.jpg
   - memory-11.jpg
   - memory-12.jpg

3. (Optional) To customize the captions and dates for each photo,
   open:
   src/data/anniversaryContent.ts
   and edit the "gallery" section!

Any format (JPG, PNG, WebP) will work. If using a different file name
or extension, just update the path in `src/data/anniversaryContent.ts`.
